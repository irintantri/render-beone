1.  Frontend
1.1Overview

The "Edit and Refine" feature provides a user-friendly interface for reviewing and polishing Informed Consent Form (ICF) documents generated by AI. It allows users to view the document in organized sections, make manual adjustments, and leverage AI assistance to rewrite or improve specific parts of the text. This ensures that the final document is accurate, professional, and tailored to specific study requirements.

1.2Step-by-Step Flow
1.Document Loading: Upon entering the editor, the system automatically retrieves the generated ICF and displays it as a series of organized cards.
2.Section Review: You can scroll through the document, where each section is clearly labeled with its title and number. Sections created by the AI are marked with a specific badge for easy identification.
3.Initiating Edits: When you identify a section that needs refinement, you can select the "Edit with AI" button on that specific card.
4.Manual Refinement: A dedicated editing window opens, displaying the current text. You can manually type, delete, or rewrite the content directly in this area.
5.AI Processing: If you choose to use AI assistance, the system will process your request and update the section. During this time, a visual indicator will appear to let you know the system is working on the update.
6.Progress Tracking: Throughout the process, a progress bar at the top of the screen keeps you informed of your current stage within the overall ICF creation workflow.
1.3Key Concepts
–Section-Based Editing: The document is broken down into manageable chunks, allowing you to focus on one part of the ICF at a time rather than the entire document at once.
–AI-Assisted Refinement: A tool that allows you to combine your human expertise with AI capabilities to rewrite or improve the clarity and tone of the document.
–Visual Status Indicators: Clear markers (such as badges and loading spinners) that help you distinguish between AI-generated content and your own edits, and show you when the system is actively processing changes.
–Workflow Progress: A navigation guide that shows you exactly where you are in the four-step ICF creation process, ensuring you know what has been completed and what remains.
1.4Business Value

This feature significantly reduces the time and effort required to finalize complex legal and medical documents. By providing a hybrid approach—where the AI handles the heavy lifting of drafting and the user maintains full control over the final content—the organization can ensure high-quality, compliant ICFs are produced faster. This minimizes manual errors, improves consistency across documents, and allows staff to focus on high-level review rather than repetitive drafting tasks.

2.  Logic
2.1Overview

This feature enables the system to retrieve and display the full details of an Informed Consent Form (ICF) whenever a user opens a document for review or editing. By automatically loading the document's content, metadata, and current status, the system ensures that users always have the most up-to-date version of the form ready for refinement.

2.2Step-by-Step Flow
1.Initiation: When a user navigates to the document editing screen, the system automatically triggers a request to fetch the specific document.
2.Data Retrieval: The system searches the database for the document record associated with the unique ID of the selected file.
3.Validation: The system confirms the document exists. If the document cannot be found, an error message is displayed to the user.
4.Display: Once located, the system pulls the full document record—including its name, version, current status, and the actual text content—and populates the editing interface so the user can begin their work.
2.3Key Concepts
–Document Metadata: The background information about the file, such as its name, version number, and the dates it was created or last modified.
–Document Status: The current state of the ICF (e.g., draft, under review, or published), which helps users understand where the document is in the lifecycle.
–Primary Read Endpoint: The standard "fetch" action the system performs to ensure the screen is populated with accurate, real-time information every time a user opens a document.
2.4Business Value

This feature provides a seamless user experience by ensuring that the editing environment is instantly populated with the correct document data. By automating the retrieval process, it eliminates the need for manual searching or refreshing, allowing users to focus immediately on the task of reviewing and refining the ICF content. This reliability is essential for maintaining accuracy and efficiency in the document management workflow.

3.  Data
3.1Overview

The ICF Creation - Edit and Refine feature provides a robust environment for users to review, adjust, and finalize Informed Consent Forms (ICFs). This feature acts as the foundation for document management, ensuring that once an ICF is generated, users have a reliable way to retrieve the document’s current state, including its text content, version history, and associated metadata, so they can perform manual edits or trigger AI-assisted refinements.

3.2Step-by-Step Flow
1.Document Retrieval: When a user selects an ICF to edit, the system fetches the specific document using its unique identifier.
2.Data Loading: The system retrieves the full document profile, which includes the document name, current version, status, and the actual text content.
3.Metadata Access: The system loads additional background information (metadata) associated with the document, such as tracking details or specific configuration settings.
4.Display for Refinement: The retrieved information is presented in the interface, allowing the user to view the current draft and begin the editing or refinement process.
5.Error Handling: If the document cannot be found or if there is a system issue during retrieval, the user is notified immediately to ensure data integrity.
3.3Key Concepts
–Document Profile: The complete set of information regarding an ICF, including its title, version number, and current status (e.g., draft or published).
–Metadata: Supplemental information attached to the document that helps track its history and specific attributes without cluttering the main document text.
–Version Control: The ability to track different iterations of the ICF, ensuring users are always editing the correct and most recent version.
–Read-Only Retrieval: A secure process that ensures the document is safely loaded into the editor without accidentally modifying the source data until the user explicitly saves their changes.
3.4Business Value

This feature streamlines the document lifecycle by providing a reliable "single source of truth" for ICFs. By enabling seamless retrieval and display, it reduces the time spent searching for document versions and ensures that clinical teams can confidently refine content. This leads to higher quality documentation, improved compliance, and a more efficient workflow for preparing consent forms.
