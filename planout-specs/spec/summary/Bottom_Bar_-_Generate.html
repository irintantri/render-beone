1.  COMPONENTS
1.1Overview

The "Generate" page features a bottom navigation bar designed to give users flexibility while they are in the process of creating content. This bar provides two clear paths for users to exit the current generation screen, depending on whether they want to restart their configuration or move forward to the editing phase.

1.2Step-by-Step Flow
1.Back to Setup: If a user decides they need to change their initial configuration, they can select the "Back to Setup" button. This immediately returns them to the creation screen.
2.Skip: If a user prefers to bypass the current generation process and move directly to the editing stage, they can select the "Skip" button. The system verifies the current job information and then transitions the user to the editor for that specific task.
1.3Key Concepts
–Ghost Button: A secondary button style that is visually subtle, ensuring the primary action on the page remains the focus while still providing clear navigation options.
–Navigation Logic: The system ensures that the "Skip" function only works if a valid job is currently active, preventing errors if the system cannot identify which task the user is trying to edit.
–Flexible Workflow: The ability to either return to the beginning or jump ahead allows users to control their own pace and correct mistakes without being forced to complete the current step.
1.4Business Value

This feature improves the user experience by reducing frustration. By providing an "escape hatch" to return to the setup phase, users can easily correct errors. By providing a "Skip" option, power users or those who have already configured their settings can move through the application more efficiently, ultimately increasing the speed at which they can reach the final editing stage.
