1.  Frontend
1.1Overview

The ICF Creation Setup feature is a guided, three-step wizard designed to help users prepare the necessary information for generating an Informed Consent Form (ICF). By centralizing protocol selection, document management, and template choice into one interface, the system ensures that all required inputs are correctly configured before the AI generation process begins.

1.2Step-by-Step Flow
1.Protocol Selection: The user begins by selecting a clinical protocol from a list. A search tool is available to quickly filter protocols by name or ID once at least three characters are entered.
2.Document Attachment: Once a protocol is selected, the user attaches essential reference materials, such as the Investigator’s Brochure or Lab Manual. Users can either fetch these from the document management system or upload them directly.
3.Template Selection: The user chooses a document template to define the structure of the ICF. A "standard" template is selected by default, but users can choose others based on descriptions and recommendations provided in the interface.
4.Validation and Launch: Throughout the process, the system validates that a protocol is selected before allowing document uploads. Once all steps are complete, the user is ready to trigger the AI generation.
1.3Key Concepts
–Protocol: The specific clinical study plan that serves as the foundation for the ICF.
–Reference Documents: Supporting files (like brochures or manuals) required to provide accurate information for the ICF.
–Template: A pre-defined document structure that ensures the generated ICF meets specific formatting and content standards.
–Wizard: A step-by-step interface that guides the user through a complex task, ensuring no required information is missed.
–Validation: Automated checks that prevent errors, such as ensuring a protocol is chosen before attempting to attach documents.
1.4Business Value

This feature streamlines the ICF creation process by replacing manual, fragmented workflows with a single, intuitive interface. By guiding users through the necessary setup steps, it reduces the risk of human error, ensures consistency across all generated documents, and significantly accelerates the time it takes to prepare an ICF for clinical trials.

2.  Logic
2.1Overview

The ICF (Informed Consent Form) Creation Setup feature provides a guided, three-step wizard designed to help users prepare the necessary information for AI-assisted document generation. By centralizing protocol selection, document management, and template choice, the system ensures that all required inputs are correctly linked before the generation process begins.

2.2Step-by-Step Flow
1.Protocol Selection: Upon opening the wizard, the system loads a list of available protocols. Users can either browse the full catalog or use a search function (requiring at least three characters) to find a specific protocol by name or ID.
2.Reference Document Management: Once a protocol is selected, the system retrieves any existing reference documents associated with that specific protocol.
3.Document Upload: If additional reference materials are needed, users can upload files (such as PDFs, Word documents, or text files). The system validates the file type and securely stores the document, linking it directly to the selected protocol.
4.Template Selection: The user selects an appropriate ICF template from a pre-defined catalog. This ensures the generated document follows the required organizational standards.
5.Launch: With the protocol, reference documents, and template confirmed, the setup is complete and the user is ready to trigger the AI generation process.
2.3Key Concepts
–Protocol: The foundational clinical study framework that dictates the requirements for the ICF.
–Reference Documents: Supporting files (like study protocols or background information) that the AI uses as context to generate an accurate ICF.
–Template: A standardized document structure that serves as the starting point for the AI to ensure consistency and compliance.
–Wizard: A user-friendly interface that breaks the setup process into logical, sequential steps to prevent errors and ensure all necessary data is captured.
2.4Business Value

This feature streamlines the administrative burden of preparing clinical documents. By enforcing a structured workflow, it reduces the risk of missing critical information, ensures that generated documents are always mapped to the correct study protocol, and significantly accelerates the time-to-draft for complex ICFs.

3.  Data
3.1Overview

The ICF (Informed Consent Form) Creation Setup feature is a guided, three-step wizard designed to streamline the preparation of new consent documents. By centralizing the selection of clinical protocols, supporting reference materials, and standardized templates, the system ensures that users have all the necessary information organized before triggering the AI-driven generation process.

3.2Step-by-Step Flow
1.Protocol Selection: The user begins by searching for and selecting the specific clinical protocol relevant to the new ICF. The system provides details such as the protocol name, phase, and category to ensure the correct study is identified.
2.Reference Document Attachment: Once the protocol is selected, the user uploads or attaches the necessary reference documents. These files are linked directly to the chosen protocol to provide the AI with the context required for accurate document drafting.
3.Template Selection: The user chooses a standardized ICF template from the available catalog. The system highlights "recommended" templates to help the user select the most appropriate format for their specific study requirements.
4.Launch Generation: After the protocol, documents, and template are confirmed, the user initiates the AI generation process to create the draft ICF.
3.3Key Concepts
–Protocol: The foundational clinical study plan that defines the scope and requirements for the ICF.
–Reference Document: Supporting files (such as study protocols or background materials) that provide the necessary information for the AI to generate a compliant and accurate consent form.
–Template: A pre-defined document structure that ensures consistency and adherence to organizational standards.
–Recommended Template: A system-flagged option that guides the user toward the most suitable template based on the selected protocol.
3.4Business Value
–Efficiency: By consolidating the setup into a single wizard, users save time by avoiding manual document gathering and formatting.
–Accuracy: Linking reference documents directly to a specific protocol ensures that the AI has the correct context, reducing the risk of errors in the generated consent forms.
–Standardization: Using pre-approved templates ensures that all ICFs produced by the system meet organizational and regulatory quality standards.
–User Guidance: The inclusion of recommended templates simplifies the decision-making process for users, ensuring they choose the best starting point for their specific study.
