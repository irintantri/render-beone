1.1Overview

The Wrapper Shell is a standardized layout component designed to provide a consistent user experience across the five-step "Consent Creation" process. By acting as a container for every page in this workflow, it ensures that users always have access to essential navigation tools, context about the protocol they are working on, and a clear view of their progress.

1.2Step-by-Step Flow
1.Breadcrumb Display: The system renders a navigation bar that includes a link back to the main dashboard, the current process label ("Consent Creation"), and specific details about the protocol, such as its ID, name, and version.
2.Data Integration: The shell automatically gathers the necessary information (such as the current step number and protocol details) to ensure the interface is populated with the correct context for the user.
3.Workflow Context: The shell displays a progress indicator showing the user exactly where they are within the five-step creation flow, ensuring they always know how much of the process remains.
1.3Key Concepts
–Wrapper Shell: A master layout that wraps around the main content of a page to provide a uniform look and feel.
–Breadcrumb Sub-bar: A navigation element that helps users understand their location within the application and provides quick access to key identifiers like the Protocol ID and ICF version.
–Step Indicator: A visual tracker that displays the user's current progress (from step 0 to 4) out of the total five steps required to complete the task.
–Conditional Rendering: A feature where specific information (like the Protocol ID or ICF name) only appears on the screen if that data is available, keeping the interface clean and uncluttered.
1.4Business Value
–Improved User Experience: By providing a consistent "chrome" (the outer frame of the application), users can navigate the Consent Creation process intuitively without needing to relearn the interface at each step.
–Reduced Cognitive Load: Users always have immediate access to their progress and the specific protocol details they are working on, reducing the likelihood of errors or confusion.
–Development Efficiency: Because this shell is a shared component, future updates to the navigation or layout can be applied globally, ensuring the application remains maintainable and scalable as new features are added.
