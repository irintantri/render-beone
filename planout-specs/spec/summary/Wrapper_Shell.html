1.1Overview

The Wrapper Shell is a consistent layout component designed for the BeOne POC creation flow. It acts as a "frame" that surrounds the main content of each page, ensuring that users always have access to essential navigation tools and context about the specific protocol they are working on. By standardizing this layout, we ensure a uniform experience across all five steps of the consent creation process.

1.2Step-by-Step Flow
1.Global Navigation: The system displays a top bar that provides consistent access to global navigation and user identity information.
2.Contextual Breadcrumbs: A sub-bar appears below the top bar, showing the user's path. This includes a link back to the main dashboard, a static label identifying the current process ("Consent Creation"), and dynamic details about the specific protocol (such as its ID, name, and version) if that information is available.
3.Progress Tracking: A visual step indicator is displayed to show the user exactly where they are within the five-step creation flow.
4.Content Display: The main area of the screen renders the specific content for the current step, framed by the navigation and progress elements above.
1.3Key Concepts
–Wrapper Shell: A structural container that provides a consistent look and feel across different pages of the application.
–Breadcrumb Sub-bar: A navigation aid that helps users understand their location within the system and provides quick access to parent pages and specific protocol details.
–Conditional Rendering: A logic feature where specific information (like protocol ID or version) only appears on the screen if that data is currently available for the user.
–Step Indicator: A visual tool that tracks progress through a multi-step process, helping users understand how much of the task is complete.
1.4Business Value
–Improved User Orientation: By providing constant access to breadcrumbs and progress indicators, users are less likely to feel lost while navigating the multi-step consent creation process.
–Consistency: Standardizing the layout reduces cognitive load, as users do not have to re-learn the navigation structure when moving between different steps of the workflow.
–Efficiency: The dynamic display of protocol information ensures that users always have the necessary context (such as the specific protocol ID or version) visible without needing to navigate away from their current task.
