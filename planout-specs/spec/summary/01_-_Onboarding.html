1.  Frontend
1.1Overview

The Welcome Screen serves as the personalized landing page for authenticated users within the BeOne platform. It provides a professional, role-aware entry point that confirms the user's identity, displays their current work status, and highlights the platform's value proposition before they proceed to the main dashboard.

1.2Step-by-Step Flow
1.Loading Phase: Upon arrival, the system displays a full-screen spinner with the message "Signing you in…" while it securely retrieves the user's profile and task data.
2.Data Retrieval: The system automatically fetches the user's name, assigned roles, and current task counts (drafts and reviews) from the server.
3.Visual Presentation: Once loaded, the screen displays a two-column layout:

* Left Column: Features an illustration representing the platform, accompanied by key performance metrics (500+ Protocols, 99% Compliance, 3x Faster).

* Right Column: Displays a personalized welcome message, the user's initials in a circular avatar, their specific roles (color-coded for clarity), and a summary of their pending tasks.

4.Administrative Note: A footer note informs the user that their specific permissions are managed by their organization’s administrator.
5.Navigation: The user clicks the "Continue to Dashboard" button to transition from the welcome screen into the main application workspace.
1.3Key Concepts
–Role-Awareness: The interface dynamically adjusts to show the user's specific primary and secondary roles, ensuring they have visibility into their functional responsibilities.
–Task Summary: A real-time snapshot of the user's active work, specifically highlighting items currently in progress and those requiring their review.
–Authenticated Landing: A secure, personalized gateway that ensures users are recognized and informed of their status before entering the core dashboard.
–System Feedback: Clear visual indicators (loading spinners and error messages) that keep the user informed about the status of their session.
1.4Business Value
–Efficiency: By providing a summary of pending tasks immediately upon login, users can prioritize their work before even reaching the dashboard.
–User Confidence: The personalized welcome and clear display of roles reinforce that the user is in the correct environment with the appropriate access levels.
–Brand Alignment: The inclusion of platform performance metrics (compliance and speed) reinforces the value of the tool to the user every time they log in.
–Administrative Clarity: By explicitly stating how permissions are managed, the system reduces confusion and support inquiries regarding access rights.
2.  Logic
2.1Overview

The Onboarding feature provides a personalized landing page for users immediately after they log in. By identifying who the user is and what their current responsibilities are, the system creates a tailored experience that displays their profile information alongside a summary of their active tasks. This ensures that every user starts their session with a clear view of their status and workload.

2.2Step-by-Step Flow
1.Identity Verification: The system checks the user's active session to ensure they are securely logged in. If the session is missing or has expired, the user is prompted to log in again.
2.Data Gathering: Once verified, the system retrieves the user’s profile details (such as their name, role, and regional settings) and their current task metrics.
3.Personalized Dashboard Construction: The system compiles this information into a single view, combining identity details with a snapshot of their work progress.
4.Display: The user is presented with their personalized welcome screen, featuring their profile information and a summary of tasks requiring their attention.
2.3Key Concepts
–Authentication: The security process that confirms the user's identity before granting access to the dashboard.
–User Profile: The collection of personal information, such as name, contact details, and assigned roles, that defines the user within the system.
–Task Summary: A real-time snapshot of the user's current workload, including items in progress, items waiting for review, and items that have been approved or rejected.
–Role-Awareness: The system’s ability to recognize the user's specific job function, ensuring the information displayed is relevant to their responsibilities.
2.4Business Value

This feature improves user efficiency by eliminating the need to navigate through multiple screens to understand their current status. By providing an immediate, role-specific overview upon login, the system reduces cognitive load and helps users prioritize their work effectively from the moment they start their session.

3.  Data
3.1Overview

The "Onboarding" feature serves as the personalized landing page for users immediately after they log in. Its primary purpose is to verify the user's identity and instantly gather all the information needed to display a tailored dashboard. By combining profile details with a summary of current work tasks, the system ensures that users see relevant information specific to their role the moment they arrive.

3.2Step-by-Step Flow
1.Authentication Check: The system verifies the user's identity using their secure login credentials (session cookie or token). If the session is invalid or expired, the user is denied access.
2.Data Retrieval: Once verified, the system automatically fetches the user’s profile information (such as their name, role, and preferences) and their current task status.
3.Dashboard Preparation: The system compiles this data into a single package, which is then sent to the screen to populate the dashboard with the correct user-specific content and work metrics.
3.3Key Concepts
–Authenticated Session: A secure connection that confirms who the user is, ensuring they only see data they are authorized to access.
–Role-Awareness: The system recognizes the user's specific job function or permissions, allowing it to display features and information relevant to their role.
–Task Summary: A snapshot of the user's current workload, including items in progress, items waiting for review, rejected items, and items ready for publication.
–Personalized Landing: The ability for the software to "greet" the user with their specific profile and work status immediately upon entry.
3.4Business Value

This feature significantly improves the user experience by eliminating the need for multiple loading screens or manual data refreshes. By "bootstrapping" the dashboard—meaning all essential information is delivered in one go—the system allows users to immediately understand their priorities and jump straight into their work. This reduces friction, saves time, and ensures that every user has a clear, personalized view of their responsibilities from the moment they log in.
