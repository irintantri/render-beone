1.  Frontend
1.1Overview

The Welcome Screen serves as the personalized landing page for users after they log in. It provides a professional, branded greeting while offering an immediate snapshot of the user's current responsibilities and system status. By displaying role-specific information and active tasks, the screen ensures users are oriented and ready to begin their work efficiently.

1.2Step-by-Step Flow
1.Authentication Check: Upon arrival, the system verifies the user's identity. A loading screen with a spinner is displayed while this information is being retrieved.
2.Profile Display: Once authenticated, the screen displays a personalized greeting using the user's first name, accompanied by their profile avatar.
3.Role Recognition: The system highlights the user's primary and secondary roles using color-coded badges, making it clear what permissions the user holds.
4.Task Overview: The screen provides a quick summary of the user's current workload, specifically highlighting the number of drafts in progress and items currently awaiting their review.
5.Contextual Information: A side panel displays platform value propositions (such as compliance and speed metrics) alongside a disclaimer regarding administrative role management.
6.Navigation: The user can click the "Continue to Dashboard" button to proceed to their main workspace.
1.3Key Concepts
–Role-Awareness: The interface dynamically adjusts to show specific job functions (primary and secondary roles), ensuring users understand their current access level.
–Task Summary: A high-level view of pending work, designed to help users prioritize their actions immediately upon logging in.
–Authentication State: The system manages the transition from a "loading" state to a "personalized" state, ensuring a smooth user experience during the login process.
–Compliance Disclaimer: A clear notification that role-based permissions are managed by administrators, providing transparency regarding system access.
1.4Business Value
–Efficiency: By surfacing active tasks (drafts and reviews) immediately, users can jump directly into their most urgent work without searching through menus.
–User Confidence: The personalized greeting and clear display of roles reinforce that the user is in the correct environment with the appropriate permissions.
–Brand Alignment: The inclusion of platform performance metrics (e.g., compliance and speed) reinforces the value of the tool to the user every time they log in.
–Reduced Support Overhead: By explicitly stating that role permissions are managed by administrators, the system proactively answers common questions about access levels.
2.  Logic
2.1Overview

The Onboarding feature serves as the personalized "front door" for the BeOne platform. When a user logs in, the system automatically identifies who they are and what their responsibilities are. This ensures that the welcome screen is tailored specifically to the individual, displaying their name, professional role, and a quick snapshot of their current workload so they can immediately see what needs their attention.

2.2Step-by-Step Flow
1.Loading State: As soon as the user initiates the login process, the screen displays a "Signing you in..." message with a loading spinner to indicate that the system is preparing their personalized workspace.
2.Profile Retrieval: The system securely fetches the user’s identity details, including their name, profile picture, and assigned professional roles.
3.Task Summary Calculation: Simultaneously, the system scans the user's active tasks to count how many are currently in a draft state and how many are waiting for their review.
4.Personalized Dashboard Display: Once the data is ready, the screen updates to show a warm welcome message, visual badges representing the user's roles, and a summary of their pending tasks.
2.3Key Concepts
–Authenticated Landing Page: The first screen a user sees after logging in, which is customized based on their unique identity and permissions.
–Role-Aware Interface: A design approach where the information shown (such as badges and icons) changes based on the user's specific job function within the system.
–Task Summary: A high-level overview that provides immediate visibility into the user's current productivity status, specifically highlighting drafts and items requiring review.
–User Context: The collection of personal data—such as name, role, and regional settings—that allows the application to provide a relevant and localized experience.
2.4Business Value

This feature improves user efficiency by eliminating the need to navigate through multiple menus to find pending work. By providing an immediate, role-specific summary upon login, the platform reduces cognitive load and helps users prioritize their tasks as soon as they start their session. This personalized approach ensures that every user feels recognized and informed, leading to a more intuitive and professional user experience.

3.  Data
3.1Overview

The "Onboarding" feature serves as the initial handshake between the user and the application. When a user logs in, the system automatically gathers their profile information and a summary of their current workload. This ensures that the dashboard is immediately personalized and ready for use the moment the user lands on the page, without requiring them to click through multiple screens to see their status.

3.2Step-by-Step Flow
1.Authentication Check: The system identifies the user based on their secure login session. If the session is invalid or missing, access is denied.
2.Profile Retrieval: The system fetches the user’s core details, including their name, contact information, assigned roles, and regional preferences (such as time zone and language).
3.Workload Aggregation: The system scans the user's assigned tasks and categorizes them by status (e.g., drafts, items needing review, rejected items, and approved items).
4.Dashboard Initialization: The system combines the profile data and the task counts into a single summary, which is sent to the dashboard to populate the user interface.
3.3Key Concepts
–Session Context: The secure information that confirms who the user is, allowing the system to tailor the experience specifically to them.
–Role-Awareness: The system recognizes the user's specific permissions (e.g., Admin or Editor), which dictates what they can see and do within the application.
–Task Aggregation: A background calculation that counts a user's active work items, allowing the dashboard to display helpful "at-a-glance" status badges.
–Bootstrap: The process of loading all necessary information at once so the user experiences a fast, fully functional dashboard immediately upon arrival.
3.4Business Value
–Improved User Experience: By providing a personalized dashboard immediately upon login, users can see exactly what requires their attention without manual searching.
–Increased Efficiency: Consolidating profile and task data into a single step reduces the number of requests the system needs to make, resulting in a faster, more responsive application.
–Operational Clarity: Users are kept informed of their workflow status (such as rejected or approved items) in real-time, helping them prioritize their daily tasks effectively.
