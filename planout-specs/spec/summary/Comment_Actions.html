1.  components
1.1Overview

The "Comments-Actions" feature provides a collaborative workspace on the document review page. It allows reviewers to communicate via threaded comments and ensures that a document cannot be submitted for final approval until all feedback has been addressed and all reviewers have completed their required actions.

1.2Step-by-Step Flow
1.Reviewer Participation: Reviewers can view their status and confirm their participation by clicking an "Act" button, which updates their status to "acted."
2.Comment Management: Users can view existing feedback in a scrollable list on the right-hand panel.
3.Adding Feedback: Users can add new comments using a pinned composer at the bottom of the panel. When typing, they can associate the comment with a specific section of the document.
4.Validation Check: The system continuously monitors two conditions: whether all reviewers have "acted" and whether there are any remaining "open" comments.
5.Submission: Once all reviewers have acted and all comments are resolved (zero open comments), the "Submit for Approval" button becomes active, allowing the document to move to the next stage.
1.3Key Concepts
–Approval Gate: A safety mechanism that prevents a document from being submitted until all reviewers have finished their tasks and all feedback has been addressed.
–Comment Composer: A dedicated input area that allows users to attach feedback to specific parts of the document, ensuring context is preserved.
–Threaded Comments: A structured way to view feedback, including replies, to keep discussions organized and easy to follow.
–Action Status: A tracking system that monitors whether each reviewer has officially acknowledged or completed their review responsibilities.
1.4Business Value

This feature streamlines the document review process by centralizing communication and enforcing quality control. By requiring all comments to be resolved before submission, the system reduces the risk of oversight and ensures that every piece of feedback is accounted for. This creates a more disciplined, transparent, and efficient workflow for teams managing complex documentation.

2.  Logic
2.1Overview

The Comment Actions feature provides a dedicated space on the document review page for users to communicate and track feedback. This feature allows reviewers to view existing discussions, add new comments or replies, and formally signal that they have completed their review actions. By centralizing these interactions, the system ensures that all feedback is captured directly alongside the document being reviewed.

2.2Step-by-Step Flow
1.Reviewer Action: When a user clicks the "Act" button, the system updates their status to confirm they have performed their required review task.
2.Loading Comments: When the Comments tab is opened, the system automatically retrieves all existing comments and replies associated with that specific document.
3.Adding Feedback: When a user submits a new comment or a reply, the system validates the input and saves it to the document’s history, making it immediately available for others to see.
4.Cleanup: When the user navigates away from the comments section, the system clears the temporary data to ensure that the next time the tab is opened, the information is fresh and accurate.
2.3Key Concepts
–Reviewer Status: A tracking mechanism that records whether a participant has officially completed their review action.
–Comment Threading: The ability to view both original comments and their subsequent replies in a single, organized view.
–Data Persistence: The process of saving comments and review actions to the system so they remain available for future reference.
–State Management: The system's way of handling information locally while a user is viewing the page, ensuring that data is cleared when no longer needed to prevent errors.
2.4Business Value

This feature streamlines the collaboration process by removing the need for external communication tools. By linking comments directly to specific sections of a document and tracking reviewer progress, teams can achieve faster turnaround times, maintain a clear audit trail of feedback, and ensure that all stakeholders are aligned before a document is finalized.

3.  Data
3.1Overview

The Comment Actions feature provides a dedicated space within the document review page for users to communicate and track feedback. Located in a right-hand panel, this feature allows reviewers to post comments, reply to existing discussions, and manage the status of their feedback. Additionally, the system tracks whether a reviewer has completed their required actions on a document, ensuring clear visibility into the review progress.

3.2Step-by-Step Flow
1.Viewing Feedback: When a user opens a document, the system automatically retrieves all existing comments and replies associated with that specific document, displaying them in chronological order.
2.Adding Comments: A user can create a new comment or reply to an existing one. The system validates that the comment contains text and assigns it a status (such as open, resolved, or closed).
3.Saving Feedback: Once validated, the new comment is saved with a unique identifier and a timestamp, then immediately displayed in the interface to keep all reviewers updated in real-time.
4.Updating Review Status: As a reviewer interacts with the document, the system tracks their participation. Once a reviewer performs an action, their status is updated in the system to reflect that they have officially "acted" on the document.
3.3Key Concepts
–Comment Threading: The ability to link replies to a parent comment, allowing for organized, multi-turn conversations within the document.
–Comment Status: A tracking mechanism (Open, Resolved, or Closed) that helps teams manage the lifecycle of a piece of feedback.
–Reviewer Action Tracking: A status flag that confirms whether a specific reviewer has completed their required tasks, providing transparency for project managers.
–Chronological Sorting: Comments are automatically ordered by the time they were created to ensure the conversation flow is easy to follow.
3.4Business Value

This feature streamlines the collaboration process by centralizing communication directly alongside the document being reviewed. By providing a clear status for both individual comments and the reviewer's overall progress, it reduces ambiguity, prevents feedback from being overlooked, and ensures that all stakeholders remain aligned on the document's approval status.
