1.  components
1.1Overview

The Global Navigation Header is a persistent bar that sits at the top of every page within the Consent IQ platform. It serves as a consistent anchor for users, providing clear branding, quick access to important notifications, and a personalized view of their account information. By keeping this header fixed, we ensure that users always know where they are in the application and can easily manage their tasks and profile settings regardless of which page they are viewing.

1.2Step-by-Step Flow
1.Brand Identification: The left side of the header displays the platform name ("Consent IQ"), a descriptive subtitle, and the "Powered by Agilisium" attribution to establish context and ownership.
2.Persistent Layout: The header is anchored to the top of the screen, ensuring it remains visible as the user navigates through different sections of the platform.
3.Notification Monitoring: A bell icon monitors the user's current task list. If there are pending items, a badge appears on the icon to indicate the number of unread notifications.
4.User Identity Loading: The system automatically retrieves the user's profile information, including their name and role. If the system cannot retrieve this data, it defaults to generic placeholders ("User Name" and "ICF Author") to ensure the interface remains clean and functional.
1.3Key Concepts
–Global Header: A fixed navigation bar that remains visible across all pages to provide a consistent user experience.
–Notification Badge: A visual indicator on the bell icon that updates based on the number of active tasks, helping users stay informed about pending actions.
–User Identity: A personalized section displaying the user's name and role, represented by an avatar based on their initials for quick visual recognition.
–Fallback Logic: A safety mechanism that ensures the header displays default information if the system is unable to retrieve specific user data, preventing empty or broken UI elements.
1.4Business Value
–Improved Navigation: By providing a consistent header, users can orient themselves quickly, reducing confusion and increasing efficiency.
–Enhanced Productivity: The notification badge acts as a proactive alert system, ensuring users are immediately aware of pending tasks that require their attention.
–Professional Branding: The clear display of the platform name and attribution reinforces the professional identity of the Consent IQ tool.
–System Reliability: The use of fallback logic ensures that the interface remains polished and professional even if there are temporary issues with data retrieval.
2.  Data
2.1Overview

The Global Navigation Header feature provides a consistent, personalized top bar across the BeOne platform. Its primary purpose is to display essential user information—such as your name, professional role, and current task status—ensuring you always know who is logged in and what requires your attention.

2.2Step-by-Step Flow
1.Request Initiation: When you access the platform, the system automatically requests your profile information.
2.Data Retrieval: The system searches the database for your specific user profile, including your name, assigned roles, and the number of tasks currently assigned to you.
3.Validation: The system checks if your profile data is successfully found.
4.Display or Fallback:
–If your data is found, the header populates with your specific details.
–If your data is unavailable for any reason, the system displays a standard default profile (labeled as "User Name" with an "ICF Author" role) to ensure the navigation bar remains functional and professional.
2.3Key Concepts
–User Context: The collection of personal details (name, roles, and task volume) that defines your specific session on the platform.
–Fallback Logic: A safety mechanism that ensures the navigation header displays correctly even if there is a temporary issue retrieving your specific profile data.
–Task Counts: A summary metric displayed in the header that provides a quick glance at how many items currently require your action.
2.4Business Value

This feature enhances the user experience by providing a reliable, "always-on" orientation point. By centralizing identity and task information in the header, users can quickly verify their access level and stay informed about their workload without navigating away from their current task. The inclusion of fallback logic ensures that the platform remains stable and usable, preventing navigation errors even during data retrieval delays.
