1.  components
1.1Overview

The Global Navigation Header is a persistent, fixed bar that appears at the top of every page within the Consent IQ platform. It serves as the primary orientation point for users, providing clear branding, platform identification, and quick access to personal account information and system notifications.

1.2Step-by-Step Flow
1.System Initialization: As the page loads, the system automatically attempts to retrieve the current user's information and notification status from the platform's database.
2.Data Retrieval: The system fetches the user's name, assigned role, and the number of unread notifications. If the system cannot reach the database, it automatically applies default placeholder values to ensure the header remains visible and functional.
3.Brand Display: The left side of the header displays the "Consent IQ" platform name, a descriptive subtitle, and the "Powered by Agilisium" attribution.
4.Notification Alerting: The right side of the header displays a bell icon. If there are unread notifications, a small badge appears over the icon indicating the count.
5.User Identity Display: The right side also displays the user's profile information, including an avatar (represented by the user's initials), their full name, and their current role, accompanied by a dropdown menu icon for further account actions.
1.3Key Concepts
–Persistent Header: A navigation bar that stays locked at the top of the screen, ensuring users can always access their profile or notifications regardless of where they are in the application.
–Graceful Fallback: A safety mechanism that ensures the header displays default information (such as "ICF Author") if the system encounters a connection error, preventing the interface from breaking.
–Notification Badge: A visual indicator that provides immediate feedback on pending tasks or alerts without requiring the user to navigate away from their current page.
–User Context: The specific data set (name, role, and initials) that personalizes the user's experience within the platform.
1.4Business Value
–Improved User Experience: By providing a consistent navigation anchor, users can move through the platform intuitively without losing their place.
–Operational Continuity: The fallback logic ensures that even if backend services experience temporary issues, the user is not blocked from using the platform, maintaining productivity.
–Brand Recognition: The prominent display of the platform name and attribution reinforces the professional identity of the Consent IQ tool.
–Efficiency: The notification badge allows users to stay informed about important updates at a glance, reducing the need to manually check for new information.
2.  Data
2.1Overview

The Global Navigation Header is a consistent top-bar component designed to provide users with immediate access to their identity and status within the platform. It ensures that regardless of which page a user is on, they can see their name, professional role, and a summary of their current workload. The system is designed to be resilient, providing sensible default information if a user's profile data is temporarily unavailable.

2.2Step-by-Step Flow
1.The system identifies the currently logged-in user based on their active session.
2.The system retrieves the user's profile details, including their name, primary and secondary roles, and the number of tasks currently assigned to them.
3.If the system successfully finds the user, it displays their specific information in the header.
4.If the system cannot find the user (or if data is missing), it automatically displays a default profile: "User Name" with a role of "ICF Author" and zero tasks.
5.The header displays this information alongside a dropdown menu icon, allowing the user to interact with their profile settings.
2.3Key Concepts
–User Context: The collection of personal details (name, roles, and task volume) that the system uses to personalize the navigation experience.
–Resilience (Fallback Logic): A safety mechanism that ensures the navigation header remains functional and professional even if the system encounters an error or cannot retrieve specific user data.
–Task Summary: A quick-reference indicator that shows the user how many items currently require their attention.
2.4Business Value
–Improved User Experience: By providing a consistent header across the platform, users always know who is logged in and can easily access their profile.
–Operational Efficiency: Displaying task counts directly in the header helps users stay informed about their workload without needing to navigate to a separate dashboard.
–System Reliability: The fallback mechanism ensures that the interface remains clean and usable even during unexpected data issues, preventing broken layouts or confusing empty states for the end user.
