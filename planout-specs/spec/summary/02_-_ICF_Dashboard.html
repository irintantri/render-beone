1.  Frontend
1.1Overview

The Consent IQ Dashboard serves as the central command center for managing Informed Consent Forms (ICFs). It provides a high-level summary of your consent portfolio and a detailed, searchable list of all protocols, allowing users to track the status of documents and quickly navigate to specific tasks like editing or reviewing.

1.2Step-by-Step Flow
1.Dashboard Initialization: Upon loading, the system displays a summary of your consent portfolio, including the total number of forms, those currently in review, and those already approved.
2.Search and Discovery: Users can type into the search bar to instantly filter the list of protocols by name or ICF title. If the search bar is empty, the system displays the full list of protocols.
3.Sorting: Users can click on any column header (such as Protocol ID, Version, or Last Modified) to organize the data. Clicking a header toggles the order between ascending and descending, indicated by a small arrow.
4.Managing Documents: Each protocol row provides specific actions based on the document's status:

* View: Allows users to see a preview of the document.

* Open: For drafts or documents in review, this button takes the user to the editing workspace. For approved documents, it directs the user to the final preview.

5.Creating New Content: Users can click the "Create New Consent" button at any time to begin the setup process for a new document.
1.3Key Concepts
–Status Badge: A visual indicator that clearly labels the current stage of a document (e.g., Draft, In Review, or Approved) to help users prioritize their work.
–Dynamic Sorting: A feature that allows users to reorder the table instantly by clicking column headers, making it easier to find the most recently modified or specific protocol versions.
–Contextual Actions: The system intelligently determines which buttons to show (View vs. Open) based on the document's status, ensuring users are always directed to the correct workflow.
–Real-time Search: The dashboard updates the list of protocols as you type, removing the need to press "Enter" or click a search button.
1.4Business Value

This dashboard streamlines the administrative burden of managing complex clinical documentation. By centralizing all protocols into one searchable, sortable view, teams can reduce the time spent hunting for documents and gain immediate visibility into the status of their consent forms. The clear distinction between "Draft," "In Review," and "Approved" statuses helps prevent bottlenecks and ensures that users are always taking the appropriate action on the right document.

2.  Logic
2.1Overview

The ICF Dashboard serves as the central command center for managing consent forms across all research protocols. It provides users with an immediate snapshot of their workload, alongside powerful tools to organize, filter, and locate specific documents quickly. By consolidating protocol and consent form data into one view, the dashboard streamlines the administrative process for tracking document status and history.

2.2Step-by-Step Flow
1.Dashboard Initialization: Upon loading the page, the system automatically retrieves high-level summary statistics, including the total number of protocols and a breakdown of those currently "In Review" versus "Approved."
2.Protocol Listing: The system displays a comprehensive list of all protocols, including their associated consent forms and file details.
3.Sorting: Users can organize the protocol list by clicking on column headers. The system supports toggling between ascending and descending order to help users prioritize their view.
4.Searching: As a user types into the search bar, the dashboard instantly filters the list. The search functionality scans both protocol names and consent form names simultaneously to ensure relevant results are surfaced immediately.
5.Dynamic Updates: Clearing the search input automatically restores the full, sorted list of protocols, ensuring a seamless transition between focused searching and general browsing.
2.3Key Concepts
–Protocol: The primary research study container that holds specific consent form information and associated documentation.
–ICF (Informed Consent Form): The specific document associated with a protocol that is being tracked, reviewed, and managed within the dashboard.
–Dashboard Metrics: Real-time status counts that provide an immediate overview of the current workload and approval progress.
–Dynamic Filtering: The ability for the system to update the displayed list instantly based on user input or sorting preferences without requiring a page refresh.
2.4Business Value
–Improved Efficiency: By providing instant search and sorting capabilities, users spend less time hunting for documents and more time managing them.
–Enhanced Visibility: The summary statistics provide leadership and administrators with an immediate pulse on the status of all consent forms, highlighting bottlenecks in the review process.
–Centralized Management: Consolidating protocol and consent form data into a single interface reduces the need to navigate between multiple systems, minimizing errors and improving data consistency.
3.  Data
3.1Overview

The ICF Dashboard serves as the central command center for managing consent forms within the BeOne system. It provides users with a high-level summary of their current workload and a detailed, searchable list of all protocols and their associated consent forms. This feature is designed to help users quickly assess the status of their projects and locate specific documentation without navigating through multiple screens.

3.2Step-by-Step Flow
1.Dashboard Initialization: When the dashboard loads, the system automatically retrieves summary statistics, including the total number of protocols and a breakdown of those currently "In Review" versus "Approved."
2.Protocol Listing: The system displays a comprehensive list of all protocols. Users can organize this list by choosing specific sorting criteria (such as name or date) to prioritize their work.
3.Searching: Users can perform targeted searches by entering a protocol name or a specific consent form name. The system filters the entire library to display only the relevant matches.
4.Detailed View: For every protocol listed, the dashboard provides access to the associated consent form details, including version history and any linked files, ensuring all necessary information is available in one place.
3.3Key Concepts
–Protocol: The primary research or clinical study framework that acts as the parent container for all related consent forms.
–ICF (Informed Consent Form): The specific documentation associated with a protocol, which can have multiple versions and supporting files.
–Dashboard Stats: A high-level snapshot showing the volume of work and the current progress of protocols (e.g., how many are pending review).
–Work Queue: The interactive list of protocols that allows users to sort, search, and manage their active tasks efficiently.
3.4Business Value
–Improved Efficiency: By centralizing all protocol and consent form data, users spend less time searching for files and more time managing their research.
–Enhanced Visibility: Real-time status updates (In Review vs. Approved) allow managers to quickly identify bottlenecks and track the progress of consent documentation.
–Streamlined Workflow: The ability to sort and search through large volumes of data ensures that users can maintain control over complex projects with multiple versions and documents.
