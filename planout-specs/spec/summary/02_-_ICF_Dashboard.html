1.  Frontend
1.1Overview

The Consent IQ Dashboard serves as the central command center for managing Informed Consent Forms (ICFs). It provides users with a high-level overview of their consent documentation status and a searchable, sortable list of all protocols. From this hub, users can quickly monitor progress, search for specific documents, and navigate directly to creation, editing, or preview workflows.

1.2Step-by-Step Flow
1.Dashboard Initialization: Upon loading, the dashboard automatically fetches and displays summary statistics (Total, In Review, and Approved forms) and populates the main data table with all available protocols.
2.Search and Discovery: Users can type into the search bar to instantly filter the list of protocols and ICFs by name. Clearing the search box automatically restores the full list.
3.Sorting: Users can click any column header in the table to sort the data. Clicking a header once sorts the list in ascending order; clicking it again toggles the order to descending.
4.Action Selection: Depending on the status of a specific form, users can interact with the "Actions" column:

* For Drafts or In-Review forms: Users can choose to "View" (to see a preview) or "Open" (to jump into the editing and refinement tool).

* For Approved forms: Users can "View" or "Open" the document to see the final version.

5.Creating New Content: Users can click the "Create New Consent" button in the header to initiate the setup process for a new protocol.
1.3Key Concepts
–Statistics Cards: High-level summary widgets that provide immediate visibility into the volume of work currently in progress versus completed.
–Sortable Data Table: A dynamic list that allows users to organize information by various criteria (such as Protocol ID, Status, or Last Modified date) to find specific records faster.
–Status-Driven Actions: A smart interface that changes the available options based on the document's current state, ensuring users only see relevant tools (e.g., you cannot "edit" an approved document).
–Instant Search: A responsive search feature that updates the table results in real-time as the user types, reducing the need for manual filtering.
1.4Business Value
–Efficiency: Centralizing all consent forms into one dashboard eliminates the need to navigate through multiple systems or folders to find documentation.
–Visibility: Real-time statistics provide leadership and project managers with an immediate pulse on the status of consent forms across all protocols.
–Reduced Administrative Burden: By providing direct, context-aware links to editing and previewing, the dashboard minimizes the time spent searching for the right tool for the right task.
–Improved Data Management: The ability to sort and search large volumes of protocol data ensures that users can maintain control and oversight as the number of projects grows.
2.  Logic
2.1Overview

The ICF Dashboard serves as the central command center for managing consent forms. It provides users with an immediate high-level summary of their workload and offers powerful tools to locate and organize specific consent forms across various research protocols.

2.2Step-by-Step Flow
1.Dashboard Initialization: When you first open the dashboard, the system automatically retrieves a summary of your consent forms, showing the total number of forms, how many are currently under review, and how many have been approved.
2.Viewing Protocols: The system displays a comprehensive list of all protocols, including key details such as the protocol name, consent form version, current status, and the date of the last update.
3.Sorting Data: You can organize the list of protocols by clicking on column headers (such as status or last modified date) to sort the information in the order that best suits your current task.
4.Searching for Specifics: If you need to find a particular item, you can use the search function to filter the list by entering either the protocol name or the specific name of the consent form.
2.3Key Concepts
–Dashboard Statistics: A snapshot view that provides immediate visibility into the volume and progress of consent forms.
–Protocol List: The primary table containing detailed records of consent forms, including their identification, versioning, and current status.
–Sorting: A feature that allows you to reorder the list of protocols to prioritize specific information.
–Filtering: A search capability that narrows down the list of protocols based on specific keywords, helping you quickly locate relevant documents.
2.4Business Value

This feature streamlines the administrative workflow by eliminating the need to manually track consent forms across different systems. By providing a centralized view with intuitive search and sort capabilities, the dashboard reduces the time spent searching for information, minimizes the risk of missing forms in the review process, and ensures that project managers have real-time visibility into the status of all research protocols.

3.  Data
3.1Overview

The ICF Dashboard serves as the central command center for managing Informed Consent Forms (ICFs). It provides users with a high-level summary of all consent activity and a detailed, searchable list of individual forms. This feature is designed to help you quickly assess the status of your documentation and locate specific protocols without navigating through complex menus.

3.2Step-by-Step Flow
1.View Summary Statistics: Upon opening the dashboard, the system automatically calculates and displays a snapshot of your ICF portfolio, showing the total number of forms, how many are currently under review, and how many have been approved.
2.Access Detailed Records: The dashboard presents a comprehensive list of all ICFs, including key details like the protocol name, version, current status, and the date of the last update.
3.Search and Filter: You can narrow down the list of forms by entering specific keywords related to a protocol or a specific ICF name.
4.Organize Data: You can sort the list of forms by various criteria (such as status or date) to prioritize the information that is most relevant to your current task.
3.3Key Concepts
–Dashboard Statistics: A real-time summary that provides immediate visibility into the volume and progress of your consent forms.
–ICF Record: A detailed entry containing all essential metadata for a specific consent form, such as its unique identifier, version history, and current approval status.
–Search and Sort: Tools that allow you to manage large volumes of data by quickly finding specific records or reordering the list to suit your workflow.
3.4Business Value

This feature streamlines the administrative burden of managing consent forms by providing a "single source of truth." By offering both a high-level overview and granular search capabilities, it reduces the time spent searching for documents, minimizes the risk of missing forms that require attention, and ensures that project teams can maintain clear oversight of their protocol documentation status at all times.
