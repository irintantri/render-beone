1.  COMPONENTS
1.1Overview

The "Edit Actions" feature provides a centralized control bar for managing document content within the BeOne platform. It allows users to view document metadata, preview the final layout, and perform direct edits or deletions on specific sections of a document. This interface ensures that users have clear visibility into what they are working on and provides safe, controlled ways to modify document content.

1.2Step-by-Step Flow
1.Context Display: Upon loading, the system displays the document name and identification number at the top of the screen to provide immediate context.
2.Section Selection: The interface identifies and displays the title of the specific section currently selected by the user.
3.Previewing: Users can click "Preview Draft" to open a full-screen modal that displays the document as a PDF, allowing for a final review of the layout.
4.Version Awareness: A version label (e.g., "v1.0 Draft") is always visible, ensuring users know exactly which iteration of the document they are viewing.
5.Editing Content: Clicking "Edit" transforms the section into an editable text area. Users can then modify the content and choose to "Save" their changes (which updates the system) or "Cancel" to discard them.
6.Deleting Content: Clicking "Delete" triggers a confirmation prompt to prevent accidental data loss. Once confirmed, the section is permanently removed, and the document structure is automatically updated.
1.3Key Concepts
–Document Context Bar: A persistent header that displays essential information like the document name, version, and the specific section being edited.
–Preview Modal: A dedicated, full-screen view that allows users to see how their changes appear in the final document format before finalizing them.
–Edit Mode: A state-based interface that switches a section from a read-only view to an interactive text editor, providing clear "Save" and "Cancel" options.
–Delete Confirmation: A safety mechanism that requires an extra step before permanently removing a section to ensure data integrity.
1.4Business Value

This feature streamlines the document refinement process by placing all necessary management tools directly within the user's workflow. By providing real-time previewing and clear editing controls, it reduces the risk of errors and improves efficiency. Furthermore, the system automatically logs manual edits and manages document structure during deletions, ensuring that the document remains audit-ready and organized at all times.

2.  logic
2.1Overview

The Edit Actions feature provides users with the necessary tools to manage document content directly within the "Edit and Refine" page. This functionality allows users to view document details, modify specific sections of text, and remove unwanted sections, ensuring the document remains accurate and well-structured throughout the editing process.

2.2Step-by-Step Flow
1.Document Initialization: When a user opens a document, the system automatically generates a unique identifier for the document to ensure it is tracked correctly.
2.Loading Content: The system retrieves the full document, including its metadata, status, and all existing sections, and displays them in the center panel for the user to review.
3.Editing Content: When a user makes changes to a specific section, the system saves those updates immediately. It also creates an activity log entry to track that a manual edit has occurred.
4.Removing Content: If a user chooses to delete a section, the system removes it permanently. Once deleted, the system automatically reorganizes the remaining sections to ensure the document structure stays consistent and properly ordered.
2.3Key Concepts
–Document Metadata: The background information associated with a document, such as its name, version, status, and creation dates, which helps users identify and track the document's history.
–Section Editing: The ability to modify the text within a specific part of a document without needing to rewrite the entire file.
–Activity Logging: An automated record-keeping process that tracks when changes are made, providing transparency and accountability for document updates.
–Structural Re-sequencing: An automated cleanup process that ensures that after a section is removed, the remaining parts of the document are correctly ordered and formatted.
2.4Business Value

This feature streamlines the document management workflow by providing a centralized, intuitive interface for refining content. By automating the tracking of edits and the reorganization of document structure, the system reduces the risk of manual errors, saves time for the user, and ensures that all document versions remain organized and audit-ready.

3.  data
3.1Overview

The Edit Actions feature provides a centralized control bar within the "Edit and Refine" page, allowing users to manage document content efficiently. It enables users to view document details, modify specific sections of text, and remove sections when they are no longer needed. The system ensures that all changes are tracked for audit purposes and that the document structure remains organized automatically.

3.2Step-by-Step Flow
1.Document Retrieval: When you open a document, the system loads the full document, including its metadata (such as the name, version, and status) and its current content.
2.Section Modification: When you edit a specific section of the document, the system saves your changes and automatically creates an activity log entry to record that a manual edit has occurred.
3.Section Removal: If you choose to delete a section, the system permanently removes it from the document.
4.Automatic Re-sequencing: Immediately after a section is deleted, the system automatically updates the order of the remaining sections to ensure the document structure remains clean and sequential.
3.3Key Concepts
–Document Metadata: The descriptive information about a document, such as its protocol ID, version number, and current status, which helps identify and track the file.
–Activity Log: A background record that tracks manual edits, providing an audit trail of changes made to the document content.
–Section Re-sequencing: An automated process that adjusts the numbering or order of document parts after a deletion, ensuring there are no gaps in the document flow.
–Edit and Refine Page: The primary workspace where users interact with the document to make content adjustments and manage its structure.
3.4Business Value

This feature streamlines the document management process by providing a reliable, user-friendly interface for content updates. By automating the re-sequencing of sections and maintaining an audit log of all edits, the system reduces the risk of manual errors, ensures document integrity, and provides transparency for compliance and review purposes.
