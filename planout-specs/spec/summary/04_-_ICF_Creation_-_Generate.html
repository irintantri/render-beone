1.  Frontend
1.1Overview

The ICF Generation feature provides a transparent, real-time view of the document creation process. When the system begins generating an Informed Consent Form (ICF), users are presented with a dedicated dashboard that tracks progress through six specific stages. This ensures users are kept informed about the status of their request without needing to guess how much time remains or what the system is currently doing.

1.2Step-by-Step Flow
1.Initiation: Once the generation process starts, the system displays a progress dashboard showing the specific protocol being processed.
2.Real-Time Monitoring: The screen updates automatically every second, showing a progress bar and a countdown timer (ETA) to help manage expectations.
3.Stage Tracking: A checklist of six sequential steps is displayed. As the system works, each step transitions from "Pending" to "Active" (indicated by a spinner) and finally to "Done" (indicated by a green checkmark).
4.Completion: Once the final step is finished and the progress reaches 100%, the system automatically redirects the user to the document editor to review the newly created ICF.
1.3Key Concepts
–Progress Visualization: A visual representation of the generation status, including a progress bar and a step-by-step checklist, to provide clarity on the system's current activity.
–Dynamic ETA: A countdown timer that estimates the remaining time until the document is ready, helping users understand how long they need to wait.
–Automated Navigation: A seamless transition that moves the user from the waiting screen directly into the document editor as soon as the file is ready, removing the need for manual intervention.
–Generation Pipeline: The six-stage sequence the system follows, ranging from parsing protocol data to performing final compliance checks.
1.4Business Value

This feature significantly improves the user experience by replacing uncertainty with transparency. By providing a clear, step-by-step view of the generation process, users can trust that the system is actively working on their request. The automated navigation to the editor upon completion saves time and reduces friction, allowing users to move immediately from the generation phase to the review and editing phase without unnecessary clicks or delays.

2.  Logic
2.1Overview

The ICF Generation feature provides a transparent, real-time view of the document creation process. Instead of leaving you on a static loading screen, the system visually tracks the AI's progress through six distinct stages. Once the document is fully generated, the system automatically transitions you to the editor so you can begin reviewing and refining your content without needing to click any additional buttons.

2.2Step-by-Step Flow
1.Initialization: As soon as the generation process begins, the system establishes a live connection to track the progress of your document.
2.Real-Time Updates: As the AI works, the screen updates dynamically to show a progress bar and highlights which of the six sequential steps is currently being processed.
3.Status Monitoring: You will see a "Generating your ICF..." message while the work is in progress.
4.Completion: Once the AI finishes the final step, the status updates to "Finalizing..." to indicate the document is ready.
5.Auto-Navigation: After a brief pause to ensure the document is fully prepared, the system automatically redirects you to the editor screen to view your new document.
2.3Key Concepts
–Progress Visualization: A visual interface that breaks down the complex generation process into six easy-to-understand steps, keeping you informed of exactly what the system is doing.
–Live Stream: A continuous connection between the server and your screen that allows the progress bar and status labels to update instantly without you needing to refresh the page.
–Auto-Navigation: A seamless transition feature that detects when the document is ready and moves you directly to the next phase of your workflow, reducing manual effort.
2.4Business Value

This feature improves the user experience by removing the uncertainty often associated with AI-driven tasks. By providing clear, step-by-step feedback, users can trust that the system is actively working. Furthermore, the automatic transition to the editor streamlines the workflow, allowing users to move immediately from document creation to document refinement, thereby increasing overall productivity.
