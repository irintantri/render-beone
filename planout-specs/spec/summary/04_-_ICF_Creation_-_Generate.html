1.  Frontend
1.1Overview

The ICF Generation feature provides a transparent, real-time view of the document creation process. When a user initiates the generation of an Informed Consent Form (ICF), the system displays a dedicated dashboard that tracks progress through six specific stages. This ensures users are kept informed about the status of their document without needing to guess how much time remains or what the system is currently doing. Once the process reaches 100% completion, the system automatically transitions the user to the document editor.

1.2Step-by-Step Flow
1.Initialization: The system launches the generation dashboard, displaying the specific protocol being processed.
2.Real-Time Monitoring: The system automatically checks the status of the generation every two seconds to ensure the information on the screen is always up to date.
3.Visual Progress Tracking: As the system works, a progress bar fills up, and a countdown timer provides an estimated time to completion.
4.Stage Updates: A six-step checklist updates dynamically:

* Pending: Future steps are hidden.

* Active: The current step shows an animated spinner and an "In progress" label.

* Done: Completed steps are marked with a green checkmark.

5.Automatic Completion: Once the final step is finished and the progress reaches 100%, the system automatically redirects the user to the final document editor.
1.3Key Concepts
–Generation Checklist: A visual roadmap consisting of six stages: Parsing, Loading, Applying, Generating, Compliance, and Finalizing.
–Progress Polling: An automated background process that refreshes the screen data every two seconds to keep the user informed.
–Dynamic ETA: A calculated countdown timer that estimates how many minutes and seconds remain until the document is ready.
–State Indicators: Visual cues (spinners for active tasks and checkmarks for completed ones) that allow users to see exactly where the system is in the workflow.
1.4Business Value

This feature significantly improves the user experience by removing the "black box" uncertainty often associated with automated document generation. By providing clear, step-by-step feedback and an estimated completion time, users can manage their expectations and time more effectively. The automatic transition to the editor upon completion reduces manual effort and ensures a seamless workflow from document creation to final review.

2.  Logic
2.1Overview

The ICF Generation feature provides a transparent, real-time experience for users as the system creates their documents. Instead of waiting on a static loading screen, users can watch the progress of their document creation through six distinct checkpoints. Once the AI successfully completes the generation process, the system automatically transitions the user to the editing workspace to begin refining the final document.

2.2Step-by-Step Flow
1.Initialization: As soon as the generation screen loads, the system establishes a live connection to the server to begin receiving real-time updates.
2.Progress Tracking: As the AI works, the screen updates dynamically, showing a percentage bar and highlighting which of the six generation steps is currently being processed.
3.Completion: Once the server confirms the document is fully generated, the live connection is closed.
4.Automatic Transition: After a brief pause to ensure a smooth user experience, the system automatically redirects the user to the document editor.
5.Refinement: The user arrives in the editor, where they can manually edit text, request AI-assisted rewrites, manage document sections, or view a live preview of their work.
2.3Key Concepts
–Real-time Progress Visualization: A live status display that keeps the user informed about the generation progress, reducing uncertainty during wait times.
–Automated Workflow: A seamless transition from the generation phase to the editing phase, removing the need for the user to manually click or navigate once the document is ready.
–Document Editor: A dedicated workspace designed for post-generation refinement, offering tools for manual adjustments and AI-powered content improvements.
2.4Business Value

This feature improves user satisfaction by replacing "black box" processing with transparent, visual feedback. By providing a clear status of the generation pipeline, users feel more in control of the process. Furthermore, the automatic transition to the editor streamlines the workflow, allowing users to move immediately from document creation to the value-added task of refining and finalizing their content.
